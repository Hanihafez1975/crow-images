## 💾 How to Save as PDF

### Method 1: Using HTML Files (Best Quality)
1. Open the `.html` file in any web browser (Chrome, Firefox, Safari, Edge)
2. Click the "Print / Save as PDF" button on the page, OR
3. Press `Ctrl+P` (Windows/Linux) or `Cmd+P` (Mac)
4. In the print dialog, select "Save as PDF" as the destination
5. Click "Save" and choose your location

### Method 2: Using Command Line (Linux/Mac)
If you have `wkhtmltopdf` installed:
```bash
wkhtmltopdf manuscript_introduction.html manuscript_introduction.pdf
wkhtmltopdf scientific_discussion_GPx_BISDA.html scientific_discussion_GPx_BISDA.pdf
```

### Method 3: Online Conversion
1. Download the `.md` (Markdown) file
2. Use online converters like:
   - https://www.markdowntopdf.com/
   - https://cloudconvert.com/md-to-pdf
   - https://dillinger.io/ (Markdown editor with export)

## 📄 File Format Guide

### HTML Files (.html)
- **Best for:** Viewing in browser and converting to PDF
- **Features:** Formatted text, styled headers, clickable links
- **How to use:** Double-click to open in browser

### Markdown Files (.md)
- **Best for:** Editing, version control, GitHub
- **Features:** Plain text with formatting syntax
- **How to use:** Open with text editor or Markdown viewer

### Text Files (.txt)
- **Best for:** Quick reading, maximum compatibility
- **Features:** Plain text, no formatting
- **How to use:** Open with any text editor

## 🔧 Troubleshooting

### Can't open HTML files?
- Make sure you have a web browser installed
- Try right-click → "Open with" → Select your browser

### PDF conversion not working?
- Try a different browser (Chrome usually works best)
- Check printer settings in print dialog
- Ensure "Save as PDF" is selected as destination

### Files won't download?
- Check file permissions
- Try copying files to a different location
- Use command line: `cp filename.html ~/Downloads/`
